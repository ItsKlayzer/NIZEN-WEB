# NIZEN — Sitio web empresarial

## Cómo abrirlo en VS Code

1. Descarga y descomprime la carpeta.
2. Abre la carpeta `nizen_web` en Visual Studio Code.
3. Abre `index.html`.
4. La forma más cómoda de verlo es instalar la extensión **Live Server** en VS Code.
5. Haz clic derecho en `index.html` → **Open with Live Server**.

## Estructura

- `index.html` → estructura de la página.
- `styles.css` → diseño y responsive.
- `script.js` → menú móvil y año automático.
